# Reclaim
Screen time, focus, bedtime and Reels/Shorts blocker for Android. All data stays on your phone.

## Get the APK
1. Create a new GitHub repo and upload everything in this folder (keep the `.github` folder).
   If the web uploader skips `.github`, click Add file > Create new file, type
   `.github/workflows/build.yml`, and paste the contents of the build.yml from this zip.
2. Open the repo's Actions tab. Choose "Build APK" and press Run workflow
   (it also runs on every push to main).
3. When it turns green, open the run and download the `reclaim-apk` artifact. Unzip it.
4. Copy `app-release.apk` to your phone and install it.

## First launch
Allow Usage access and Accessibility. On Android 13+ open Settings > Apps > Reclaim >
the three-dot menu > "Allow restricted settings" first, or Accessibility stays greyed out.
